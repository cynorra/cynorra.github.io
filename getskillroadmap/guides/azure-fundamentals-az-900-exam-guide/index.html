1. Domain Weight Matrix & Core Concepts

The AZ-900 exam tests candidates across three foundational subject areas:

[Azure Global Hierarchy]
         │
         ├──► Management Groups (Governance across subscriptions)
         │        │
         │        └──► Subscriptions (Billing and access boundary)
         │                 │
         │                 └──► Resource Groups (Logical lifecycle containers)
         │                          │
         │                          └──► Resources (VMs, VNets, Storage Accounts)
  • 1.Describe Cloud Concepts (25–30%): Differentiating IaaS, PaaS, and SaaS; understanding shared responsibility models; private vs. public vs. hybrid vs. multi-cloud strategies; capital expenditure (CapEx) vs. operational expenditure (OpEx).
  • 2.Describe Azure Architecture and Services (35–40%): Core architectural components (Azure Regions, Availability Zones, Region Pairs, Sovereign Regions). Compute services (Virtual Machines, App Services, Azure Functions, ACI, AKS), networking (VNets, VPN Gateway, ExpressRoute), and storage tiers (Blob storage, Azure Files, hot/cool/cold/archive access tiers).
  • 3.Describe Azure Management and Governance (30–35%): Cost management, Azure Policy, Role-Based Access Control (RBAC), Resource Locks, Microsoft Entra ID (formerly Azure AD), Azure Blueprints, and compliance tools (Trust Center, Service Trust Portal).

Production Infrastructure-as-Code: Azure Bicep Policy Definition

In real corporate environments, platform engineers write declarative code rather than clicking in the Azure portal. Here is a production Bicep template enforcing region-lock governance:

// enforce-location-policy.bicep
targetScope = 'subscription'

param allowedLocations array = [
  'westeurope'
  'northeurope'
]


resource regionPolicy 'Microsoft.Authorization/policyDefinitions@2021-06-01' = {
  name: 'audit-allowed-locations'
  properties: {
    displayName: 'Enforce Compliant European Azure Regions'
    policyType: 'Custom'
    mode: 'Indexed'
    description: 'Bans resource creation outside approved regulatory EU geographic boundaries.'
    parameters: {}
    policyRule: {
      if: {
        not: {
          field: 'location'
          in: allowedLocations
        }
      }
      then: {
        effect: 'deny'
      }
    }
  }
}

2. Governance Comparison: Azure RBAC vs. Azure Policy

A common exam stumbling block is confusing authorization (RBAC) with compliance governance (Policy):

Feature DimensionAzure Role-Based Access Control (RBAC)Azure Policy
Core Question Answered"Who has permission to take an action?""What resource properties and configurations are compliant?"
Primary ScopeUser identities, service principals, group rolesResource metadata, SKUs, locations, encryption flags
Enforcement ActionGrants or denies action access (Contributor, Reader, Owner)Audits, denies, or auto-remediates non-compliant state
Typical ScenarioGranting a junior developer Reader access to production logsBanning GPU-enabled VMs ($1,000/mo) in non-production environments

3. The Zero-Cost Microsoft Learn Study Pipeline

Unlike commercial platforms that charge high monthly subscriptions, Microsoft provides the complete, authoritative AZ-900 curriculum completely free on Microsoft Learn:

  • •Module 1: Azure Fundamentals: Describe cloud concepts
  • •Module 2: Azure architecture and services
  • •Module 3: Azure management and governance
  • •Interactive Sandboxes: Microsoft Learn provides temporary, complimentary Azure sandbox subscriptions that allow you to spin up real VMs, configure storage accounts, and test resource groups without linking your personal credit card.

Hands-on Sandbox: Azure Bicep & Resource Group Automation

Demonstrate governance competence by configuring a multi-tier governance deployment in the Azure portal:

  • •Resource Group Structure: Create segregated rg-production and rg-development resource groups.
  • •Azure Policy Enforcement: Deploy an Azure Policy restricting VM sizes strictly to the cost-efficient Standard_B1s tier and banning non-compliant data residency outside your home region.

  • •Documentation: Export the ARM or Bicep JSON templates to a GitHub repository to substantiate your practical grasp of Infrastructure as Code.

Frequently Asked Questions

Q: Does the AZ-900 credential expire?

No. Unlike associate and expert-level Microsoft certifications which require annual online renewals, Microsoft Azure Fundamentals has no expiration date.

Q: How hard is AZ-900 compared to AWS Cloud Practitioner?

Both cover similar cloud abstractions, but AZ-900 places heavier emphasis on enterprise governance, Microsoft Entra ID authentication, and hybrid on-premise integrations.

Q: Can I take AZ-900 for free?

Historically, attending Microsoft Virtual Training Days yielded free vouchers. While policy updates vary by region, students with an active .edu email can verify through Microsoft Learn for significant exam discounts.
